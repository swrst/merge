# The merge catalogue

1000 items across 155 chains (940 of them in the five worlds, the rest shared and rocket parts), 129 producers, 5 worlds.

Each chain is a ladder: two of a thing make the next thing up. Chains run from 4 to 8
steps. The last item in a chain is its finale — finishing one for the first time pays
Bloom essence. *Lv* is the world level the chain wakes at.

Generated by `npm run art:manifest` from `scripts/content/` — edit those, not this.

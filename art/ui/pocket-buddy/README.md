# Pocket Buddy UI

Approved combination: option 3 transparent aqua tiles with option 1 companion, buttons and Star Chart. Board tiles use 28% opacity; original colorful world art stays visible. Shared mint panels, orange primary actions and teal secondary actions cover screens and popups. Classic UI and prior Orbital source assets are retained.

companion.png was generated with the built-in image generation tool. Prompt: A single isolated friendly floating hologram companion, small spherical white robot with one large expressive glossy turquoise eye, dark teal socket, orange ear discs and feet, short mint antenna, playful polished game art, subtle mint projection, transparent background, no purple or gold.

The runtime WebP is a resized transparent derivative. UI panels and constellation silhouettes are code-native for consistent scaling. Review script checks real game screens, image loading, overflow and save-preserving theme changes.

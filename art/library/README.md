# Art library

Cut-outs from the art sheets that are not used in the game yet, kept for the features that will use them:

- decorations, hats and seasonal tiles
- Moon Pup sizes, Zib expressions
- producer upgrade levels
- event banners, the season-pass path
- background thumbnails

The cuts are made automatically, one folder per sheet. The file name is `row_index.png`. Some files are just label text from the sheet; ignore them.
